# 🚀 Play Store Publishing Guide for GujaratiVani

This guide explains how to take this codebase and publish it as a native Android application on the Google Play Store.

## 1. Native Wrapper Setup (Capacitor)
Since this is a web-based React application, the fastest way to build an Android APK is using **Capacitor**.

1. **Install Capacitor CLI:**
   ```bash
   npm install @capacitor/core @capacitor/cli @capacitor/android
   ```

2. **Initialize Capacitor:**
   ```bash
   npx cap init GujaratiVani com.yourname.gujarativani --web-dir dist
   ```

3. **Build the Web App:**
   ```bash
   npm run build
   ```

4. **Add Android Platform:**
   ```bash
   npx cap add android
   ```

5. **Sync Code:**
   ```bash
   npx cap sync
   ```

## 2. Android Studio Configuration
1. Open the `./android` folder in **Android Studio**.
2. **App Icon:** Right-click `app` -> `New` -> `Image Asset`. Upload your logo to generate adaptive icons.
3. **Permissions:** Ensure `AndroidManifest.xml` includes:
   ```xml
   <uses-permission android:name="android.permission.INTERNET" />
   <uses-permission android:name="android.permission.RECORD_AUDIO" />
   ```
4. **Keystore:** Create a release keystore (`Build` -> `Generate Signed Bundle / APK`).

## 3. Play Store Readiness Checklist
- **App Name:** GujaratiVani - AI Translator
- **Description:** "The ultimate companion for Gujarati speakers. Translate text and voice from any language into natural Gujarati with high-quality AI-driven speech output."
- **Privacy Policy:** You can host the provided template on a simple GitHub Page or a free hosting service.
- **Screenshots:** Use the browser's responsive mode (360x800) to take clean screenshots of the Home, History, and Settings screens.

## 4. Play Console Upload
1. Log in to [Google Play Console](https://play.google.com/console).
2. Create a new app and follow the "Initial setup" tasks.
3. Upload the `.aab` file generated by Android Studio.
4. Submit for review!
